# DevOps Toolchain Research

## Version Control Systems (VCS)

### Git
**Primary Use:** Distributed version control and source code management.

### GitHub
**Primary Use:** Git repository hosting and collaboration.

### GitLab
**Primary Use:** Git hosting with built-in CI/CD capabilities.

---

## CI/CD Tools

### Jenkins
**Primary Use:** Automating build, test, and deployment pipelines.

### GitHub Actions
**Primary Use:** CI/CD automation directly from GitHub repositories.

### GitLab CI/CD
**Primary Use:** Integrated continuous integration and deployment.

---

## Infrastructure as Code (IaC)

### Terraform
**Primary Use:** Provisioning cloud infrastructure using code.

### AWS CloudFormation
**Primary Use:** Managing AWS infrastructure as code.

### Pulumi
**Primary Use:** Infrastructure provisioning using programming languages.

---

## Configuration Management Tools

### Ansible
**Primary Use:** Agentless server configuration and automation.

### Chef
**Primary Use:** Infrastructure configuration and policy management.

### Puppet
**Primary Use:** Automated configuration management at scale.

---

## Container Orchestration Tools

### Kubernetes
**Primary Use:** Deploying and managing containerized applications.

### Docker Swarm
**Primary Use:** Native Docker container orchestration.

### Nomad
**Primary Use:** Workload scheduling and orchestration.

---

## Monitoring Tools

### Prometheus
**Primary Use:** Metrics collection and monitoring.

### Grafana
**Primary Use:** Visualization and dashboards.

### Datadog
**Primary Use:** Cloud monitoring and observability.

---

## Logging Tools

### ELK Stack
**Primary Use:** Centralized log collection and analysis.

### Loki
**Primary Use:** Lightweight log aggregation.

### Fluentd
**Primary Use:** Log collection and forwarding.

## Key Learnings

- Git is the foundation of modern DevOps workflows.
- CI/CD tools automate software delivery.
- Docker provides application consistency.
- Terraform manages infrastructure using code.
- Ansible automates server configuration.
- Kubernetes manages containers at scale.
- Prometheus and Grafana provide monitoring and observability.
