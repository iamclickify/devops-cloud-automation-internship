# DevOps Fundamentals

## What is DevOps?

DevOps is a combination of **Development (Dev)** and **Operations (Ops)**.

It is a culture, set of practices, and collection of tools that help organizations develop, test, deploy, and maintain software faster and more reliably.

The primary goal of DevOps is to shorten the software development lifecycle while maintaining high quality and stability.

---

## Why Was DevOps Created?

Traditionally, development and operations teams worked separately.

### Development Team Responsibilities
- Writing code
- Adding features
- Fixing bugs

### Operations Team Responsibilities
- Deploying applications
- Managing servers
- Monitoring systems

This separation often caused delays, communication gaps, and deployment failures.

DevOps was introduced to bridge this gap and encourage collaboration.

---

## What Are Silos?

A silo is a situation where teams work independently with little communication or collaboration.

### Example

Developer:
> "The application works on my machine."

Operations:
> "The application crashes in production."

Since both teams work separately, nobody takes ownership of the complete software delivery process.

DevOps removes these silos by encouraging shared responsibility and collaboration.

---

## DevOps Lifecycle

The DevOps lifecycle consists of the following stages:

1. Plan
2. Develop
3. Build
4. Test
5. Release
6. Deploy
7. Operate
8. Monitor

These stages form a continuous loop that enables rapid and reliable software delivery.

---

## CALMS Framework

CALMS is a commonly used DevOps model.

### C - Culture
Focus on collaboration and shared responsibility.

### A - Automation
Automate repetitive tasks such as testing and deployment.

### L - Lean
Reduce waste and improve efficiency.

### M - Measurement
Track metrics and performance indicators.

### S - Sharing
Share knowledge, tools, and feedback across teams.

---

## Benefits of DevOps

### Faster Delivery
- Faster software releases
- Shorter development cycles
- Quicker feedback

### Improved Reliability
- Fewer deployment failures
- Better system stability
- Faster recovery from incidents

### Increased Efficiency
- Reduced manual work
- Better resource utilization
- Higher team productivity

## DevOps Tool Categories

| Category | Purpose |
|-----------|----------|
| Version Control | Manage source code changes |
| CI/CD | Automate build, test and deployment |
| Containerization | Package applications consistently |
| IaC | Manage infrastructure using code |
| Configuration Management | Configure servers automatically |
| Orchestration | Manage containers at scale |
| Monitoring | Track system health |
| Logging | Analyze application logs |

---

## Key Takeaways

- DevOps combines Development and Operations.
- Collaboration is more important than individual teams.
- Automation is a core principle of DevOps.
- DevOps improves speed, reliability, and efficiency.
- Git, Docker, Kubernetes, Terraform, and Ansible are common DevOps tools.
